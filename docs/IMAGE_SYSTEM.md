# Système d’images

Types admis: `real-photo`, `technical-illustration`, `generated-illustration`, `placeholder`.

- La photo du profil est une vraie photographie fournie dans le CV.
- Les schémas de domaines sont des illustrations techniques réalisées en HTML/CSS.
- Une illustration n’est jamais présentée comme preuve d’une intervention.
- Toute image publique doit posséder un texte alternatif et une origine dans `content/media-manifest.json`.

Les futures photos réelles vont dans `public/images/projects/<slug>/`; les originaux privés ou contenant des informations client ne doivent pas entrer dans le dépôt.
