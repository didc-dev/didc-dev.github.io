# Déploiement GitHub Pages

Le workflow installe les dépendances, contrôle les imports, le typage et le lint, construit l’export statique, exécute les tests puis publie `dist/client`.

La variable `NEXT_PUBLIC_SITE_URL` construit les métadonnées canoniques. Le compte GitHub n’est pas affiché comme identité professionnelle dans l’interface.
