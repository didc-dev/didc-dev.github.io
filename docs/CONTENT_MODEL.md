# Modèle de contenu

Chaque réalisation possède un `slug` stable, un statut, un type explicite, un domaine, un pilier, un contexte, un objectif, le rôle de Daniel, les travaux réalisés, les difficultés, l’approche, le résultat, les limites, les compétences, les outils et le type d’image. Seul le statut `published` peut rejoindre la sortie publique.

Types publics: expérience professionnelle, réalisation professionnelle, projet personnel et laboratoire d’apprentissage. Images: photographie réelle, illustration technique, illustration générée ou placeholder.

Les dates ou équivalences incertaines sont formulées prudemment. Un article réglementaire reste brouillon tant qu’une source officielle récente n’a pas été vérifiée.
