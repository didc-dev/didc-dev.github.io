# Modèle de contenu

Chaque réalisation possède un `slug` stable, un statut, un contexte, les travaux réalisés, les difficultés, la solution, le résultat, les compétences et les outils. Seul le statut `published` peut rejoindre la sortie publique.

Les dates ou équivalences incertaines sont formulées prudemment. Un article réglementaire reste brouillon tant qu’une source officielle récente n’a pas été vérifiée.
